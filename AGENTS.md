# AGENTS.md

## General
- Act autonomously. 
- If requirements or implementation direction are unclear, ask the user immediately. Never guess.
- Keep changes focused. Avoid overengineering and excessive defensive programming.
- Write clean, reusable, readable, and maintainable code.

## Frontend
- Build modern, minimal, responsive interfaces.
- Use smooth animations and meaningful interactions.
- Favor visual hierarchy over text-heavy layouts.
- Avoid tiny explanatory text, excessive labels, and visual clutter.

## Backend
- Prioritize functionality and code quality equally.
- Keep architecture simple, efficient, and maintainable.
- Avoid redundant abstractions, unnecessary layers, and premature optimization.
- Improve relevant existing code when beneficial.

## Documentation
- Keep documentation brief, clear, and practical.
- Include relevant code examples.
- Avoid redundant explanations and obvious comments.

## Testing
- Run only necessary, relevant tests.
- Avoid excessive testing and unnecessary test infrastructure.

## Git
- Commit after each completed logical change.
- Use clear, concise commit messages.
- Never push directly to `main` or `master`.
- Preserve unrelated changes.

**Principle:** Stay autonomous. Ask when uncertain. Keep everything simple.
