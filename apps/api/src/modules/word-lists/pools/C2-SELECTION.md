# C2 advanced selection

`lexiplay-c2.json` is a versioned learning collection expanded from the original 80-word curated starter using the [Octanove Vocabulary Profile C1/C2 v1.0](https://github.com/openlanguageprofiles/olp-en-cefrj), created by Octanove Labs and published under CC BY-SA 4.0. The CSV is pinned to commit `d4e45b75b38f27b30dfc5c44d8c571aec7e7092f`, SHA-256 `18c33a407f2f89f7b8de9671c6d45fe3ea0bce45e7d2d7dcaab48d73e0f7b380`. The original starter consulted [ESL Lounge](https://www.esl-lounge.com/student/reference/c2-cefr-vocabulary-word-list.php). The result is not an official or exhaustive CEFR inventory.

The selection now contains 942 distinct headwords, 978 lemma/POS entries and 731 published BNC/COCA families. All admitted additions have a dictionary definition for their intended word class and an explicit published family match. Slash-separated spellings are expanded; duplicates merge; the explicitly reviewed source typo `remonstrate:vern` is corrected to verb. Candidates lacking matching family/definition evidence, and candidates whose notes require review of a particular sense, are quarantined rather than given guessed levels or meanings. The import report records 127 omitted source lemma/POS candidates, including 13 with sense notes. Existing starter entries are preserved. Level evidence is assigned to individual members, never inherited from a family headword.

Each entry stores a lemma and word classes only. Meanings remain dictionary-resolved at runtime; no source definitions are imported. Attribution and the adapted CC BY-SA 4.0 datasets are accessible through the Licenses page. Dictionary definitions retain their original licences independently.

Rebuild from the repository root with `pnpm cefr:expand-c2` after obtaining the pinned CSV in `.local-backups/c2-expansion/` and the official Nation source in `.local-backups/word-families/bnc-coca/`. The expander reads only the local dictionary, preserves existing C2 membership, and writes the versioned source JSON and private report. Run `pnpm cefr:build-families` afterwards to regenerate the API map and public data exports. The normal collection seeder applies the additive selection without replacing personal entries or progress.

Before expanding this collection, check spelling, the intended word class, dictionary coverage, and the usefulness of the selected sense for proficiency learners. Validate additions against multiple references and context; a difficult word alone does not establish a universal CEFR level. The existing dictionary remains authoritative for displayed definitions.

Collection and game pool identifiers differ: the collection is `cefr-c2`, and the pool is `lexiplay-c2`. Saved collection membership maps through the pool's level, so C2 is never attributed to Oxford. The normal idempotent collection seeder enables C2 on the next API startup and collection request without changing personal lists or learning progress.
